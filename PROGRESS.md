## Decisions & gotchas

- API tests run once in their own project, not per browser.
- Visual + axe tests run on desktop Chromium only (`test.skip` with a reason elsewhere). Baselines are per OS:
  `results-table-chromium-win32.png` (local) and `-linux.png` (from the CI job).
- "Not submitted" assertions wait for the confirmation navigation (bounded) instead of checking the URL right after
  click, which raced on WebKit.
- The UI can't select the same city (lists share none); the same-city defect is server-side and is tested with a
  direct POST.
- Restful-Booker: token goes in a `Cookie: token=...` header; create = 200, delete = 201, repeat delete = 405.
- The CI summary counts known defects from JUnit `<property name="fail">`.
- No Playwright MCP was available; exploration was scripted (recorded in AI_WORKFLOW.md).
